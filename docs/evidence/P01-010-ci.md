fails the guard until its CI state becomes active. Active workspaces require real lint, typecheck, test:unit and build scripts;
every listed check, including extra integration/contract suites, must exist and execute successfully. No missing check can
be quietly skipped. Root `npm run ci` dispatches them independently by workspace.

| CI-09 | Invalid JavaScript, malformed JSON and trailing whitespace | Each produces an actual lint error |
| CI-10 | Synthetic credential pattern and local environment file | Rejected; matched value absent from diagnostics |
| CI-11 | Configured lint command exits 7 | Pipeline exits 1, report Failed, later unit step does not run |
| CI-12 | Configured active workspace build exits 9 | Pipeline exits 1; workspace build recorded Failed |

Tests use temporary fixture repositories and restore/clean their own data. Child CLI processes have isolated test-runner
context. Node's no-isolation test mode gives individual result reporting for these subprocess-oriented tooling tests;
fixtures remain isolated per test with cleanup. This does not configure application test isolation or waive future suites.

The generated `test-results/ci.json` records UTC start/end, Node/npm, Git base commit, working-tree state, lock digest,
workspace states, executed check results and pipeline result. It is ignored as runtime output; GitHub will upload the exact
allowlisted summary on a hosted run. This record preserves the local observations independently of ephemeral output.
